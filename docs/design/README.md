# Design Documents

Design notes for the RimWorld Anomaly Sightstealer Colony project.

## Documents

- [The Dark One](the-dark-one.md) - custom storyteller identity, goals, rewards, and Anomaly philosophy.
- [Visibility and Favour](visibility-and-favour.md) - the persistent knowledge/attention system and The Dark One's hidden Favour system.
- [Umbral Events](umbral-events.md) - Sightstealer-specific incidents, environmental events, rewards, horror events, wildlife events, and Purifier operations.
- [Rift Materials](rift-materials.md) - new resources, properties, sources, and intended uses.
- [Rift Flora](rift-flora.md) - resource-producing and decorative plants for the Rift biome.
- [Rift Architecture](rift-architecture.md) - proposed buildings, construction materials, psychological effects, and architectural progression.

These documents describe the intended design. Values and individual features should remain subject to implementation constraints and playtesting.
